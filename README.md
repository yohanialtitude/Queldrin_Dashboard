## Firebase Authentication

The app uses the Firebase project configured in `src/firebase.ts`. In the Firebase
console, enable **Email/Password** and **Google** under Authentication providers,
and add the app's hostname to the authorized domains. Email sign-up, sign-in,
password reset, Google sign-in, and session persistence are handled by Firebase
Authentication.

Workspace resources, workloads, allocations, decisions, and activity are stored in
Firestore under `users/{uid}` so each account has private data. New accounts get
their own seeded demo workspace. Deploy `firestore.rules` before using Firestore:

```sh
firebase deploy --only firestore:rules --project queldrin-608a0
```

The rules restrict all workspace reads and writes to the authenticated owner. Do
not replace them with public read/write rules.
